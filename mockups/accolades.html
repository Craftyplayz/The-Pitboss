Accolades

The game's own end-of-match accolades, shown on recaps and collected on profiles. Real names and stat values (match 127132809); icons are placeholder glyphs.

What the API gives us
  • Match metadata DOES include awarded accolades. Each match_info.players[].accolades[] is {accolade_id, accolade_stat_value, accolade_threshold_achieved}. Achieved -1 = not earned; 0, 1, 2... = earned at that tier index. The bot does not compute anything.
  • GET /v1/assets/accolades (31 entries) gives only id, class_name, flavor_name, tracked_stat_name, description (a template with {stat_value}), threshold_type (automatic / manual) and optional enabled_game_modes. No icons and no threshold numbers, so tier colours here are our own guess and icons need our own art or emoji.
  • Every player gets a row for every accolade with their raw stat, so "closest to earning" progress is free.
Not the same as Trophies. Trophies (core/trophies.py) are the bot's own lifetime tiers computed from match history (e.g. Slayer = 250 career kills). Accolades are the game's per-match badges, awarded when one match's stat passes a threshold. Overlap: kills, assists, souls, healing and damage exist in both, but a trophy is a career total and an accolade is a single match. Accolades get their own tab and a round medal icon (trophies are cups); where both show together, tag them ACCOLADE / TROPHY.
